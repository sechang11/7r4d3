New machine? Start here.
Grab all four, put them in one folder, fill your token into the .json, then double-click Update-EA-GUI.bat — that is the one with a window. After this it updates the EA, the template and itself; you never download by hand again.
Prefer a console?
Update-EA.bat does the same job with scrolling text instead of a window. Both drive the same Update-EA.ps1.
  1. Download the file for your platform. The template goes in MQL5/Profiles/Templates instead — apply it with right-click chart → Template.
  2. Save it into your terminal's MQL5/Experts (or MQL4/Experts) folder, replacing the old one. Find it via File → Open Data Folder.
  3. Open it in MetaEditor and press F7 to compile. Expect 0 errors, 0 warnings.
  4. Remove the EA from your chart and drag it back on, so the new build loads.
  5. Re-enter your inputs if prompted — the webhook and bridge token are not stored in the file.
